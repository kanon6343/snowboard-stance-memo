# スタンスメモ

スノーボードの板・ビンディング・スタンスと滑走メモを記録する、インストール可能なWebアプリです。

公開先: https://kanon6343.github.io/snowboard-stance-memo/

## 主な機能

- 簡易入力／詳細入力を切り替え。板名とビンディング名の入力候補、板の形状、スタンス幅、左右の角度・ビス位置・推奨位置、フォワードリーン、セットバック、ディスク、ヒールカップを必要に応じて記録。
- 保存履歴のカード／詳細一覧／板ごと表示、絞り込み・統計・お気に入り、内容の編集。保存後は対象の履歴へ移動。
- ライト／ダーク／端末に合わせる表示。左右のメニュー、スワイプ、下書きの復元、最後の入力／履歴画面の記憶。
- 基本編と詳細編の使い方ガイド。説明中のサンプル履歴は保存せず、実際の入力・履歴も変更しない。
- JSONの書き出しと復元。追加／日時重複を除いて追加／明示確認後の上書きに対応。
- PWAインストールとオフライン起動。詳細は [PWA.md](PWA.md)。

## 以前の版と保存履歴

- [オリジナル版](original/) は更新前の公開ページ3ファイルをそのまま保存したものです。
- [新しい独立試作版](https://kanon6343.github.io/snowboard-stance-memo-trial/) と、従来の dev-haru-detail/、dev-haru/、dev/ は別途維持しています。
- 正式版の保存キーは main:。オリジナル版の無接頭辞キー、試作版の haru-detail:、既存作業版の haru: には書き込みません。起動時の自動コピーは行いません。
- 正式版のメニュー → データ → バックアップ →「以前の版から履歴を引き継ぐ」で、同じブラウザーの試作版／オリジナル版の履歴を読み取り、件数・内容の概要を確認できます。復元方法を選んで確認するまで保存しません。
- 他の端末・ブラウザー・インストール済みアプリにある履歴は、元の版で書き出したJSONを選んで復元します。自動同期はありません。
- 日時重複を除く追加は、同じ日時の既存記録を優先します。編集済みの内容を比較・統合する機能ではありません。必要な元のバックアップは残してください。

## 公開と検証

表示バージョンは v2.3.3。オリジナル版をv1、今回作り直したアプリ全体をv2として扱います。機能追加は中央、不具合修正は右の数字を上げる運用です。キャッシュ用の内部リリース番号は1086で、表示バージョン・保存形式とは別です。

通常のメニューは探すから開きます。左側は「データ／表示／探す」の並びで、探すから左へ払うと格納。右側は並びと格納方向を反転。上側にカテゴリタブを固定し、入力欄の操作と縦スクロールは保持します。案内からの目的指定オープンは、そのタブを優先します。

ルートの正式版は release 1086。全バージョン付きアセットと sw.js の RELEASE を同時に更新します。試作版のファイル・保存キー・PWA開始URLは変更していません。

オフラインキャッシュには、このアプリが列挙した画面・静的ファイルだけを保存します。履歴やJSONバックアップはキャッシュしません。他の版のキャッシュは削除しません。個人のバックアップ・写真・測定データ、artifacts/ 内の検証ツールは公開対象に含めません。

実機の設定値を記録するアプリです。ディスクやヒールカップの図は模式図で、メーカーの互換性・取扱説明書の代わりにはなりません。

## v2.1.5の改善

- 探すを入力モード別に整理。スタンス幅は「ぴったり／範囲」、詳細ではビンディング名・ディスク形式・対象の足も検索できます。詳細の板形状は常時表示し、簡易入力では詳細専用の条件を適用しません。
- メニューのカテゴリタブは上部に配置。見出し横の版番号は廃止し、更新欄に集約。
- 更新待ちのService Workerから版番号を取得し、通知と更新ボタンへ表示。旧形式などで取得できない場合は番号を推測せず従来の更新操作を維持。新しい表示はこの版へ更新後の次回通知から使えます。
- オフライン用の画面・静的ファイルはHTTPキャッシュの古い内容を使わずに取得し直します。
- 保守時はsw.jsのAPP_VERSIONを表示版と合わせ、RELEASEと全アセット参照を同時に更新します。正式版のmain:、PWA識別情報、通常アイコンは維持しています。

## v2.2.0の改善

- 簡易／詳細入力から左スワイプで保存履歴へ、保存履歴から右スワイプで入力へ移動。タブのタップも維持。入力途中や編集中の値を保持し、スワイプだけでは保存・上書きしません。同じ起動中のスワイプ往復では画面内の位置も復元します。
- 入力欄、ボタン、ビス穴、左右足の選択、履歴レイアウト、横スクロール領域は本来の操作を優先。端32pxはメニューやOS用です。メニュー、確認画面、ガイド、下書き復元案内中は移動しません。履歴のカード／詳細一覧／板ごとはタップ操作です。
- メニューで簡易／詳細入力を実際に変更した時にメニューを閉じます。起動、下書き復元、ガイドなどの自動変更は対象外です。
- 正式版のmain:データ、PWAの識別情報、通常アイコン、オリジナル版、試作版を維持します。

## v2.3.3の改善

- 試作v2.3.3で確認した短い入力・履歴スワイプ、メニュー開始範囲の拡大、メニュー全体からの格納を正式版へ反映。入力欄・縦スクロール・タブ切り替えを維持します。
- メニュー→データに折りたたみ式の更新内容を追加。更新前の説明は、この版の画面を読み込んだ後の次回更新から確認できます。
- 復元IDの重複・不正値を整理し、元の記録と未知の項目を保持。保存済み数値IDの操作、削除直前の保護・競合確認、読み取り失敗時のバックアップ中止、時差を含む日時順を修正。起動だけで履歴を一括書き換えることはありません。
- 正式版のmain:保存先、以前の版からの確認付き引き継ぎ、通常アイコン、PWA識別情報、オリジナル版・各試作版は維持。
