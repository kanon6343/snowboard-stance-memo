# 詳細試作版のインストール

HTTPSの `dev-haru-detail/` をChromeまたはEdgeで開き、ブラウザーのメニューからインストールします。既存版とは別アプリ・別の保存履歴になります。対応環境ではアプリ内メニューにもインストールボタンが表示されます。iPhone・iPadではSafariの共有メニューから「ホーム画面に追加」を選びます。ブラウザーやOSによって表示名・対応状況は異なります。

インストール前にJSONバックアップを保存してください。履歴は端末のブラウザー内に保存され、自動同期されません。インストールしたアプリで履歴が見えない場合はバックアップから復元してください。アンインストールやサイトデータ削除で履歴が失われる場合があります。

## オフラインと更新

通信可能な状態で一度開き、メニューに「オフラインで開く準備ができました」と出るまで待ちます。その後は保存済みの画面と端末内の履歴を利用できます。OSによるキャッシュ削除や初回準備前は通信が必要です。

メニューの「最新版を確認」で新しい版を準備できます。更新通知が出たら、この画面と別のタブの入力を保存し、「入力を確認して更新する」を押します。入力中に自動で再読み込みはしません。

## 保守時の注意

- `sw.js` の `RELEASE` と `index.html` の全CSS・JSの `?v=` は同じ新しい番号へ更新します。同一番号でキャッシュ内容を変更しないでください。
- 必要な静的ファイルは `sw.js` の `SHELL` に列挙します。JSONバックアップや個人データは追加しません。
- Service Workerの登録範囲とキャッシュ削除範囲は、この `dev-haru-detail/` のみです。通常版、`dev/`、既存の `dev-haru/` には適用しません。
- マニフェストの識別子は解決済みの `start_url` を使用します。公開ディレクトリを変更すると別アプリになる可能性があります。
- アイコンは承認されたオレンジのスノーボード画像です。通常版192px・512px、Apple用180px、マスク対応512pxを用意しています。マスク対応版のみ端末側の切り抜きに備えた余白を残しています。

ストアへの配布やネイティブAPKの生成は、このPWA対応には含みません。
