# スタンスメモ 詳細試作版

安定して使っているdev-haru/とは別に、詳細入力モードを開発するための試作です。メニューの「入力モード」でシンプル／詳細を切り替えられます。切り替えだけでフォームの詳細データは消えません。未保存の入力を再起動後まで保持するものではないため、再読み込み前には保存してください。

## 詳細モード

- 元の入力画面に関連する詳細項目を組み込みます。板名の下に板の形状、スタンス幅の下にセットバック、左右の足タブ内・ビス穴より前にその足のフォワードリーンとディスク調整を表示します。ギア調整メモは既存のコメント欄内です。
- シンプル表示では追加項目だけを隠します。非表示側の足に入力エラーがある場合は、その足のタブを開いて対象欄を案内します。
- シェイプ・ノーズ形状・ベンドと形状の補足。これら3項目で保存履歴を絞り込めます。「未設定」は旧記録も対象です。
- 保存済みの板名を選択／確定すると、その板の最新の「形状あり」記録から形状だけを自動入力します。未保存の入力は記憶しません。形状を手入力していたら上書きせず、明示的な適用ボタンを表示します。履歴の設定を読み込む場合はその記録の形状をそのまま使います。
- 左右のフォワードリーンをメーカー独自の表記で記録。
- セットバックの基準は「推奨位置から／中心から」の横セグメントで切り替えます。方向は「＋ノーズ側／−テール側」の縦セグメントと符号付きmm入力が連動します。基準変更だけでは数値を換算しません。旧データの方向＋絶対量という保存形式は変更せず、読み込み時に符号へ変換します。
- ディスク方式は左右別に穴位置式／長穴スライド式／併用／その他を選択。ヒールカップは別項目で、各足の内側（親指側）／外側（小指側）の目盛りを自由記入します。0や文字をそのまま保存し、mmへ換算しません。模式図は実物の寸法・可動範囲・互換性を表していません。
- 旧試作のhighbackというディスク形式値は、読み込み時に独立したヒールカップの「旧試作で記録済み」情報へ移します。未知の内外の目盛りは推測せず空欄。ディスク移動量は元のディスク移動量として残し、ヒールカップの値に転用しません。読み込みだけでは保存済み原本を書き換えません。
- ディスク前後のずらしは＋ノーズ側、−テール側、左右共通のmm表記。0と未入力を区別。横はつま先／かかとの方向とmmを選択。
- 詳細モードでは簡易版のディスク前／中／後を隠します。値は消さず、シンプルに戻したときに再表示します。
- 保存履歴も詳細モードだけ、板の形状・左右のリーン／ディスク調整・セットバック・ギア調整メモを元のカードへ組み込みます。シンプル表示では従来の履歴レイアウトを保ち、保存時にも詳細データを保持します。
- 基準セグメントはクリック／タップと矢印キーに対応し、選択をaria-pressedで示します。符号は全体44×44pxの単一ボタンを押すたびに＋／−を切り替えます。Enter／Spaceでも操作可能。0（-0・0.0を含む）ではハイライトを消して無効化します。空欄は0とは異なり、選択状態を保って操作できます。数値を再入力すると符号に応じて有効化します。動きを減らす端末設定ではハイライトのアニメーションを止めます。
- 方向スイッチは数値欄の左側に＋／−だけを縦に並べ、全体の高さを数値欄とそろえます。読み上げには方向名も残します。履歴の左右共通項目は共通見出しの下に左／右の値を並べ、項目名を重複させません。
- 詳細入力では角度とフォワードリーンを横並びにします。シンプル表示ではリーンだけを隠し、元の角度・簡易ディスク配置を保ちます。
- セットバックは基準セグメント／符号ボタン／数値＋mmを横一列に表示します。基準の見えるラベルは「推奨位置／中心」に短縮し、読み上げでは「推奨位置から／中心から」を保持します。基準変更での自動換算は行いません。
- ディスク形式の左に模式図・説明、右に形式選択を並べ、縦方向の占有を抑えます。履歴レイアウトはこの変更では改変しません。
- 通常のJSONバックアップにも詳細を含めます。旧記録は詳細なしで読み込み可能。試作前の版で読み込み・再保存すると新項目を保持できない場合があるため、原本バックアップは残してください。

## 後で検討すること

- 画面と仕様が固まったら短いチュートリアルを作る案（かのんの提案）。モード切り替え、符号・基準・単位、保存とバックアップを案内する。現時点でチュートリアルは未実装。
- ヒールカップ入力とバックアップ／読み戻しは試作済み。ヒールカップ専用の履歴表示は後の履歴UI改編で検討する。左右非対称調整を推奨するものではなく、実機の取扱説明書に従った設定の記録用とする。
- ヒールカップの内外入力の上に、各足で共通の「手前から／奥から」の数え方メモを追加。未選択を許し、同じ選択をもう一度押すと解除できます。変更しても目盛りやディスク移動量を反転・換算しません。旧記録に基準を推測して補いません。保存先はdetail.heelcup.left/right.origin（near/far/空欄）です。
- ビス穴の図には左右それぞれ「ビス穴・推奨位置」の小見出しを表示します。ディスクを目盛りで数える入力方式は未実装で、現行の中央からの移動量（mm）とは混同しません。
- 数える基準のスイッチはヒールカップ見出しと同じ行に表示します。
- 詳細入力のセットバック下・足選択の上に、左右共通のビンディング名メモ（メーカー・モデル・サイズなど、128文字まで）を追加。detail.bindingNameとしてそのセッティングに保存し、シンプル表示でも値を保持します。板名に固定で紐づけたり、板の形状と一緒に自動入力したりはしません。履歴の専用表示は後のUI改編で検討します。
- ビンディング名はこの試作版の保存履歴から入力候補を表示します。空欄・非文字列・同じ名前の重複を除き、新しい記録順に最大20件を表示。入力による部分一致検索は全候補が対象で、英字の大小・全角半角を吸収します。未保存の入力は候補に追加しません。別の候補DBや通信は使いません。
- ビンディングの候補を明示的に選ぶと、同じ名前の最新の保存記録から左右のディスク形式とヒールカップ（内外の目盛り・数える基準）だけを反映します。最新記録で未入力の項目を古い記録から補いません。入力中の該当設定は置き換わりますが、板名・角度・フォワードリーン・セットバック・ビス穴・推奨位置・ディスクのずらし量は変更しません。名前の手入力・フォーカス・履歴の設定全体の読み込みでは、この追加呼び出しを行いません。

## 分離

- ホーム画面・タブ用のアイコンは青地に白文字の「試作」バッジ付き。短い表示名も「スタンス 試作」として通常版と区別します。通常版のアイコンは変更せず、試作版内の旧画像も残しています。maskable画像はボードとバッジが中央の安全領域に収まるよう余白を付けています。

- フォルダ・PWA開始URL・Service Worker登録範囲はdev-haru-detail/。
- 履歴、UI、配色、メニュー位置の保存キーはharu-detail:。
- アプリ名は「スタンスメモ 詳細試作版」。キャッシュ名も既存版と別。
- データは空の状態から開始し、既存版の履歴は自動コピーしません。必要な場合だけ、JSONバックアップを明示的に復元します。
- バックアップ出力のenvとファイル名にもharu-detailを付けます。
- オフライン用キャッシュには画面・静的ファイルだけを保存します。履歴やバックアップJSONは入れません。
- 同一オリジン内の保存キー分離であり、セキュリティ上の別オリジン隔離ではありません。

試作版の公開先は `/snowboard-stance-memo/dev-haru-detail/` です。既存版 `/dev-haru/` への統合はしていません。既存版のファイル・保存データを変更せず、こちらは独立した空の履歴から開始します。
