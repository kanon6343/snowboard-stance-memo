# スタンスメモ 詳細試作版

安定して使っているdev-haru/とは別に、詳細入力モードを開発するための試作です。メニューの「入力モード」でシンプル／詳細を切り替えられます。切り替えだけでフォームの詳細データは消えません。未保存の入力を再起動後まで保持するものではないため、再読み込み前には保存してください。

## 詳細モード

- 元の入力画面に関連する詳細項目を組み込みます。板名の下に板の形状、スタンス幅の下にセットバック、左右の足タブ内・ビス穴より前にその足のフォワードリーンとディスク調整を表示します。ギア調整メモは既存のコメント欄内です。
- シンプル表示では追加項目だけを隠します。非表示側の足に入力エラーがある場合は、その足のタブを開いて対象欄を案内します。
- シェイプ・ノーズ形状・ベンドと形状の補足。これら3項目で保存履歴を絞り込めます。「未設定」は旧記録も対象です。
- 保存済みの板名を選択／確定すると、その板の最新の「形状あり」記録から形状だけを自動入力します。未保存の入力は記憶しません。形状を手入力していたら上書きせず、明示的な適用ボタンを表示します。履歴の設定を読み込む場合はその記録の形状をそのまま使います。
- 左右のフォワードリーンをメーカー独自の表記で記録。
- セットバックの基準は「推奨位置から／中心から」の横セグメントで切り替えます。方向は「＋ノーズ側／−テール側」の縦セグメントと符号付きmm入力が連動します。基準変更だけでは数値を換算しません。旧データの方向＋絶対量という保存形式は変更せず、読み込み時に符号へ変換します。
- ディスク方式は左右別に穴位置式／長穴スライド式／併用／その他を選択。模式図は実物の寸法・可動範囲・互換性を表していません。
- ディスク前後のずらしは＋ノーズ側、−テール側、左右共通のmm表記。0と未入力を区別。横はつま先／かかとの方向とmmを選択。
- 詳細モードでは簡易版のディスク前／中／後を隠します。値は消さず、シンプルに戻したときに再表示します。
- 保存履歴も詳細モードだけ、板の形状・左右のリーン／ディスク調整・セットバック・ギア調整メモを元のカードへ組み込みます。シンプル表示では従来の履歴レイアウトを保ち、保存時にも詳細データを保持します。
- セグメントはクリック／タップと矢印キーに対応し、選択をaria-pressedで示します。動きを減らす端末設定ではハイライトのアニメーションを止めます。
- 方向スイッチは数値欄の左側に＋／−だけを縦に並べ、全体の高さを数値欄とそろえます。読み上げには方向名も残します。履歴の左右共通項目は共通見出しの下に左／右の値を並べ、項目名を重複させません。
- 詳細入力では角度とフォワードリーンを横並びにします。シンプル表示ではリーンだけを隠し、元の角度・簡易ディスク配置を保ちます。
- 通常のJSONバックアップにも詳細を含めます。旧記録は詳細なしで読み込み可能。試作前の版で読み込み・再保存すると新項目を保持できない場合があるため、原本バックアップは残してください。

## 後で検討すること

## 分離

- フォルダ・PWA開始URL・Service Worker登録範囲はdev-haru-detail/。
- 履歴、UI、配色、メニュー位置の保存キーはharu-detail:。
- アプリ名は「スタンスメモ 詳細試作版」。キャッシュ名も既存版と別。
- データは空の状態から開始し、既存版の履歴は自動コピーしません。必要な場合だけ、JSONバックアップを明示的に復元します。
- バックアップ出力のenvとファイル名にもharu-detailを付けます。
- オフライン用キャッシュには画面・静的ファイルだけを保存します。履歴やバックアップJSONは入れません。
- 同一オリジン内の保存キー分離であり、セキュリティ上の別オリジン隔離ではありません。

試作版の公開先は `/snowboard-stance-memo/dev-haru-detail/` です。既存版 `/dev-haru/` への統合はしていません。既存版のファイル・保存データを変更せず、こちらは独立した空の履歴から開始します。
