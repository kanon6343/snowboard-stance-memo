# スタンスメモ 詳細試作版

安定して使っているdev-haru/とは別に、詳細入力モードを開発するための試作です。メニューの「入力モード」でシンプル／詳細を切り替えられます。切り替えだけでフォームの詳細データは消えません。未保存の入力を再起動後まで保持するものではないため、再読み込み前には保存してください。

## 詳細モード

- 詳細モードの保存履歴には「カード／詳細一覧／板ごと」のセグメントを表示します。初期表示は詳細一覧。選択はこの試作版だけの `haru-detail:history-layout-v1` に記憶します。3案同時表示・架空データ・配色などの比較ページ専用ツールは組み込みません。シンプルモードは従来の履歴表示のままです。
- カードは要点を先に、ディスク・ヒールカップ・ビス穴などは開いて確認。詳細一覧は左右の詳細を常時表示。板ごとは板内も既存メニューの並び順を保ち、変更点は表示中の過去記録の角度・幅だけを比較します。日時不明・不正・タイムゾーン未確定など、前後関係を確定できない値では変更点を推測しません。
- 表示の切り替えは履歴や入力中のフォームを更新しません。お気に入り・保護・削除・設定の呼び出しは既存の処理を共有します。数字の0も未入力と区別して表示・読み込みします。
- 3表示のセグメントは保存履歴パネルの先頭（入力／保存履歴タブの直下）に置きます。詳細モードでは重複する「保存履歴」の見出し・説明を隠し、セグメントの下に板の絞り込みを並べます。入力画面やシンプルモードではセグメントを表示せず、シンプルモードの見出し・説明は従来どおり残します。

- 元の入力画面に関連する詳細項目を組み込みます。板名の下に板の形状、スタンス幅の下にセットバック、左右の足タブ内・ビス穴より前にその足のフォワードリーンとディスク調整を表示します。ギア調整メモは既存のコメント欄内です。
- シンプル表示では追加項目だけを隠します。非表示側の足に入力エラーがある場合は、その足のタブを開いて対象欄を案内します。
- シェイプ・ノーズ形状・ベンドと形状の補足。これら3項目で保存履歴を絞り込めます。「未設定」は旧記録も対象です。
- 保存済みの板名を選択／確定すると、その板の最新の「形状あり」記録から形状だけを自動入力します。未保存の入力は記憶しません。形状を手入力していたら上書きせず、明示的な適用ボタンを表示します。履歴の設定を読み込む場合はその記録の形状をそのまま使います。
- 詳細入力の「同じ板の履歴へ反映…」で、現在入力しているシェイプ・ノーズ形状・ベンド・形状の補足を、同じ板名の保存履歴へまとめて反映できます。空欄は反映せず、既存値を保持します。板名は前後の空白を除いた完全一致で、絞り込みに関係なくすべての保存履歴が対象です。確認画面に入力内容、変更件数、異なる値の上書き件数、お気に入りの対象件数を表示し、OKを選んだ場合だけ保存します。角度・ビス位置・日時や未知の項目を含む他のデータは保持します。確認中に別画面で履歴が変更された場合は反映を止め、再確認を案内します。通常の入力や新規保存だけで過去の形状を自動変更することはありません。
- メニューの「探す → 保存履歴の統計を見る」から、記録数・板の数・お気に入り数、板ごとの記録数と多く記録した角度／幅、全体の角度・幅の上位5設定、スタンス・雪質の割合を確認できます。すべての保存履歴を端末内で集計し、保存データや絞り込み条件は変更しません。記録数は滑走日数ではなく保存件数です。左右の角度が両方入力済みの記録と、正のスタンス幅だけを各設定のランキングに含めます。未設定を0として数えず、0°は入力値として扱います。板名未入力は板の数から除外し、スタンス・雪質の未設定は割合の内訳に含めます。同数の最多設定がある場合は、その旨も表示します。
- 左右のフォワードリーンをメーカー独自の表記で記録。
- セットバックの基準は「推奨位置から／中心から」の横セグメントで切り替えます。方向は「＋ノーズ側／−テール側」の縦セグメントと符号付きmm入力が連動します。基準変更だけでは数値を換算しません。旧データの方向＋絶対量という保存形式は変更せず、読み込み時に符号へ変換します。
- ディスク方式は左右別に穴位置式／長穴スライド式／併用／その他を選択。ヒールカップは別項目で、各足の内側（親指側）／外側（小指側）の目盛りを自由記入します。0や文字をそのまま保存し、mmへ換算しません。模式図は実物の寸法・可動範囲・互換性を表していません。
- 旧試作のhighbackというディスク形式値は、読み込み時に独立したヒールカップの「旧試作で記録済み」情報へ移します。未知の内外の目盛りは推測せず空欄。ディスク移動量は元のディスク移動量として残し、ヒールカップの値に転用しません。読み込みだけでは保存済み原本を書き換えません。
- ディスク前後のずらしは＋ノーズ側、−テール側、左右共通のmm表記。0と未入力を区別。横はつま先／かかとの方向とmmを選択。
- 詳細モードでは簡易版のディスク前／中／後を隠します。値は消さず、シンプルに戻したときに再表示します。
- 保存履歴も詳細モードだけ、板の形状・左右のリーン／ディスク調整・セットバック・ギア調整メモを元のカードへ組み込みます。シンプル表示では従来の履歴レイアウトを保ち、保存時にも詳細データを保持します。
- 詳細履歴の表示設定がまだない場合は「カード」から開始します。切り替えた後は最後に選んだカード／詳細一覧／板ごとの表示を、この端末の試作版用キーに記憶します。既存の有効な選択は上書きせず、不明な設定値はカードへ戻します。
- 詳細モードの3つの履歴表示に「編集」を追加。角度・ビス穴・推奨位置・板名・コメント・詳細設定などを既存の入力画面で修正し、変更項目の確認後に同じ履歴を更新します。記録の識別子・元の日時・お気に入り状態・他の履歴の内容や並び順は保持し、件数は増やしません。「この設定を使う」は従来どおり新規保存用の呼び出しです。編集をやめると未保存の入力をクリアして履歴へ戻り、確認画面の「編集に戻る」では編集中の値を残します。
- 編集中は保存ボタンの横に「キャンセル」を表示し、通常の「クリア」と入れ替えます。上部の「編集をやめる」と同じ操作です。★付きの履歴は編集を押した段階で確認し、「編集する」を選ぶまで入力画面へ移りません。確認中に対象が変わった場合は編集を開始しません。保存・キャンセル・変更なしでの終了後は、編集元のカード（板ごとの表示では該当記録）へスクロールしてフォーカスを戻します。元の記録が現在の一覧にない場合は一覧タブへ戻り、その旨を案内し、絞り込み条件は変更しません。
- 履歴を読み込んだだけでは保存せず、未設定の項目を既定値で補いません。実際に変更した項目だけを反映し、未知の付加データや未変更の旧ビス穴形式も保持します。同じ履歴の外部変更・削除・識別子の重複、確認中の履歴変更、保存エラーでは上書きを止めます。編集中の入力は残すので、必要に応じて控えてから履歴を読み直せます。形状を他の履歴へまとめて反映する操作は、1件の編集を保存または終了してから行います。
- 基準セグメントはクリック／タップと矢印キーに対応し、選択をaria-pressedで示します。符号は全体44×44pxの単一ボタンを押すたびに＋／−を切り替えます。Enter／Spaceでも操作可能。0（-0・0.0を含む）ではハイライトを消して無効化します。空欄は0とは異なり、選択状態を保って操作できます。数値を再入力すると符号に応じて有効化します。動きを減らす端末設定ではハイライトのアニメーションを止めます。
- 方向スイッチは数値欄の左側に＋／−だけを縦に並べ、全体の高さを数値欄とそろえます。読み上げには方向名も残します。履歴の左右共通項目は共通見出しの下に左／右の値を並べ、項目名を重複させません。
- 詳細入力では角度とフォワードリーンを横並びにします。シンプル表示ではリーンだけを隠し、元の角度・簡易ディスク配置を保ちます。
- 入力画面の左足／右足タブは、下へスクロールすると入力カード内で上部に追従します。画面上端から8px（端末の安全領域が大きければそちら）に置き、固定メニューボタンと同じ段に並べます。上端に近づくとメニュー側だけ横幅を空け、左／右メニューのどちらにも対応します。角度や穴数の要約は一行で表示し、収まらない末尾だけ省略します。既存の入力要素を切り替えるため、左右の値を維持します。履歴画面では表示しません。横方向のはみ出し抑制をbodyのoverflow-x:clipで行い、追従を妨げる余分なスクロール領域を作らないようにしています。
- 足タブが追従している間だけ、画面上端・左右端からタブ下10pxまでを不透明な背景で囲います。裏の入力文字が端や角から見えないようにし、メニューボタンは手前に残します。元の配置へ戻ると囲いも消え、上側の入力欄を隠しません。ライト／ダークの配色に追従します。
- コメント欄の「感想を消す」とギア調整メモ欄の「調整メモを消す」は、それぞれ該当する入力だけをクリアします。もう片方や保存済み履歴は変更せず、履歴の編集では保存時の確認を経て反映します。どちらかが入力されていれば、詳細モードのコメント見出しに「入力あり」を表示します。シンプル表示では調整メモとそのボタンは隠し、値を保持します。
- セットバックは基準セグメント／符号ボタン／数値＋mmを横一列に表示します。基準の見えるラベルは「推奨位置／中心」に短縮し、読み上げでは「推奨位置から／中心から」を保持します。基準変更での自動換算は行いません。
- ディスク形式の左に模式図・説明、右に形式選択を並べ、縦方向の占有を抑えます。履歴レイアウトはこの変更では改変しません。
- 通常のJSONバックアップにも詳細を含めます。旧記録は詳細なしで読み込み可能。試作前の版で読み込み・再保存すると新項目を保持できない場合があるため、原本バックアップは残してください。

## 後で検討すること

- 画面と仕様が固まったら短いチュートリアルを作る案（かのんの提案）。モード切り替え、符号・基準・単位、保存とバックアップを案内する。現時点でチュートリアルは未実装。
- ヒールカップ入力とバックアップ／読み戻しは試作済み。詳細モードの3つの履歴表示では、内外の値と数える基準を左右別に確認できます。左右非対称調整を推奨するものではなく、実機の取扱説明書に従った設定の記録用とする。
- ヒールカップの内外入力の上に、各足で共通の「手前から／奥から」の数え方メモを追加。未選択を許し、同じ選択をもう一度押すと解除できます。変更しても目盛りやディスク移動量を反転・換算しません。旧記録に基準を推測して補いません。保存先はdetail.heelcup.left/right.origin（near/far/空欄）です。
- ビス穴の図には左右それぞれ「ビス穴・推奨位置」の小見出しを表示します。ディスクを目盛りで数える入力方式は未実装で、現行の中央からの移動量（mm）とは混同しません。
- 数える基準のスイッチはヒールカップ見出しと同じ行に表示します。
- 詳細入力のセットバック下・足選択の上に、左右共通のビンディング名メモ（メーカー・モデル・サイズなど、128文字まで）を追加。detail.bindingNameとしてそのセッティングに保存し、シンプル表示でも値を保持します。板名に固定で紐づけたり、板の形状と一緒に自動入力したりはしません。詳細モードの履歴には名前だけを表示し、重複する「ビンディング」の見出しは省きます。
- ビンディング名はこの試作版の保存履歴から入力候補を表示します。空欄・非文字列・同じ名前の重複を除き、新しい記録順に最大20件を表示。入力による部分一致検索は全候補が対象で、英字の大小・全角半角を吸収します。未保存の入力は候補に追加しません。別の候補DBや通信は使いません。
- ビンディングの候補を明示的に選ぶと、同じ名前の最新の保存記録から左右のディスク形式とヒールカップ（内外の目盛り・数える基準）だけを反映します。最新記録で未入力の項目を古い記録から補いません。入力中の該当設定は置き換わりますが、板名・角度・フォワードリーン・セットバック・ビス穴・推奨位置・ディスクのずらし量は変更しません。名前の手入力・フォーカス・履歴の設定全体の読み込みでは、この追加呼び出しを行いません。

## 分離

### 入力保護と履歴の改善（1054）

- 入力タブとメニューの呼び名を「簡易入力／詳細入力」に統一。簡易履歴の重複する見出し・説明は、表示件数／全件数を示す共通バーに置き換えています。
- 履歴の件数と絞り込み条件は、足選択と同様に上部へ追従します。条件を一つずつ、またはまとめて解除でき、まとめて解除しても並び順・お気に入り優先・角度の許容幅は維持します。メニューを左右どちらに置いても横に空間を空け、不透明な背景で裏の文字を隠します。角度検索では未入力と0°を区別します。
- 入力途中の下書きは `haru-detail:editor-draft-v1` に一時保存し、再起動後は「再開／破棄」を選びます。選ぶまでは入力欄の操作を止め、別の履歴で下書きを上書きしません。下書きは保存履歴とは別で、JSONバックアップの対象外です。保存やクリアが完了したら下書きも解除します。保存済みと同じ内容のまま再読み込みしても、下書きの復帰は求めません。
- 履歴編集の下書きは元の記録の状態も保持し、再開時に同じ記録が変わっていなければ編集を再開します。元の記録が変更・削除されていれば新規入力として戻し、元の履歴を勝手に上書きしません。別のタブが下書きを更新した場合も、自動で上書き・削除しません。
- 保存失敗では入力を残して通知します。読めない履歴を空扱いして通常の保存・追加復元で上書きせず、元データのテキスト退避と再確認を案内します。「上書きして復元」は既存の明示確認を維持します。アプリ更新前にも下書きの退避を試し、退避できない場合は更新を止めます。
- ローカル確認には `artifacts/` の架空データ用サーバーを使います。テスト画面・架空データ・テストコード・スクリーンショットをアプリの公開ファイルに含めません。実機スマートフォンでの確認は公開後に行います。

- メニューは固定の「探す／表示／データ」タブに分け、縦に長い設定一覧を短くしています。板の形状の絞り込みは折りたたみ、指定した条件数を見出しに表示します。条件指定済みで初期化した場合は開きます。カテゴリの選択はページを再読み込みするまで保持し、保存データは変更しません。既存の入力、復元、更新、左右からのスワイプ操作は同じコントロールを使います。更新待ちのときは「データ」タブにも「更新あり」を表示します。
- 入力欄の空の選択肢「未設定／選択」だけを少し薄く表示します。値を選ぶと通常の濃さに戻り、履歴の呼び出しやクリアにも追従します。絞り込みで明示的に選んだ「未設定」と履歴の「未入力」は薄くしません。例文の薄さは変更しません。

- UI共通層 `ui-consistency.css` は最後に読み込みます。入力画面・シンプル履歴・詳細履歴の＋と×を同じ中心配置の線描画にそろえ、×の白い背景は両テーマで使いません。入力用のタップ枠とサイズは保持します。詳細モードだけ、ラベル14px／入力値16px／補足12pxを基本に、角度とリーン・ディスク移動量のラベル行と入力欄の軸をそろえます。板名・角度などの強調や、横一列に収める小さな操作部は意図的な差として残します。例文の薄さ・保存形式・操作ロジックは変更しません。

- ホーム画面・タブ用のアイコンは青地に白文字の「試作」バッジ付き。短い表示名も「スタンス 試作」として通常版と区別します。通常版のアイコンは変更せず、試作版内の旧画像も残しています。maskable画像はボードとバッジが中央の安全領域に収まるよう余白を付けています。

- フォルダ・PWA開始URL・Service Worker登録範囲はdev-haru-detail/。
- 履歴、UI、配色、メニュー位置の保存キーはharu-detail:。
- アプリ名は「スタンスメモ 詳細試作版」。キャッシュ名も既存版と別。
- データは空の状態から開始し、既存版の履歴は自動コピーしません。必要な場合だけ、JSONバックアップを明示的に復元します。
- バックアップ出力のenvとファイル名にもharu-detailを付けます。
- オフライン用キャッシュには画面・静的ファイルだけを保存します。履歴やバックアップJSONは入れません。
- 同一オリジン内の保存キー分離であり、セキュリティ上の別オリジン隔離ではありません。

試作版の公開先は `/snowboard-stance-memo/dev-haru-detail/` です。既存版 `/dev-haru/` への統合はしていません。既存版のファイル・保存データを変更せず、こちらは独立した空の履歴から開始します。
