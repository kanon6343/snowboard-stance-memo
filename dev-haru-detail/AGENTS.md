# 詳細入力モード試作版

このディレクトリは、既存版 dev-haru/ に影響させず詳細入力モードを試すための独立コピーです。上位のAGENTS.mdに従ってください。

- ここでの機能作業は原則このディレクトリ内だけを編集し、既存のdev-haru/、dev/、ルートのアプリを変更しません。
- 履歴・UI・テーマ・メニュー位置のlocalStorageキーはharu-detail:で分離します。既存版の保存先へ書き込んだり、起動時に自動コピーしたりしません。
- Service Workerはこのディレクトリの範囲のみ。既存版のキャッシュを消さないでください。
- 実バックアップ・個人のSTANCER結果・アクセスキーをソースへ埋め込んだり、公開したりしません。
- 大きな仕様変更のため、まず試作・検証を行い、既存版への統合や公開は別途確認します。
- 更新時はindex.htmlの全バージョン付きアセットとsw.jsのRELEASEを同時に上げます。

## 試作機能の方針

- メニュー内のシンプル／詳細入力切り替えを端末に記憶。シンプルに戻しても詳細データを消さない。
- フォワードリーンは左右別の自由表記。
- セットバックは基準を「推奨位置／板の中心」で選択。基準変更だけで勝手に換算しない。
- ディスクの前後ずらしは左右とも＋ノーズ／−テールのmm。横はつま先／かかとを選ぶ。方式は穴位置式／スライド式／併用／その他の模式的分類で、メーカー・互換性・寸法を断定しない。
- 板のシェイプとベンドは別項目として任意入力し、形状の補足を用意。
- 板の形状による履歴の絞り込み。古い未入力記録はそのまま保持し、未設定も扱う。
- スタンス幅は両モードで利用可能にする。
- 詳細版が固まった後のチュートリアル案をREADMEに記録済み。ユーザー依頼なしにチュートリアルを先行実装しない。
