# 履歴デザイン比較

既存アプリとは独立した3案の比較ページです。採用案を決める前の試作であり、既存の履歴UI・データ構造は変更していません。

- カード：オレンジの上辺と板名ヘッダーで1件のまとまりを明確にし、左右角度とスタンス幅を3列で表示。下部に詳細の開閉と設定確認をまとめます。リーン・ビンディングは要点として表示し、板の形状・詳細調整・ビス穴は初期状態で閉じています。
- 詳細一覧：左右を列、設定項目を行として常時表示。ディスク形式・ヒールカップのラベルを共通化。「詳細を常時表示」と明記し、カードとの違いを示します。
- 板ごとの履歴：板名単位でまとめ、各板の中は新しい順。前の記録と角度・幅を文字で比較。絞り込み中は「表示中の記録」の比較であり、保存済み全履歴の前回ではありません。

## 操作

3案の外枠は共通です。オレンジの上辺を3px、周囲は細いニュートラル色の線、角丸は20pxに統一。ライトは控えめな影、ダークは影なしです。板ごとの履歴は板のグループ全体だけを囲い、個々の日時の記録には同じ枠を重ねません。設定確認ダイアログの中には、この外枠を追加しません。

共通調整：3案ともビス穴の＋と推奨位置の×は文字の字形ではなく中心配置の線で描画。×の背景は透明で、ライトでは黒、ダークでは明色です。カードと詳細一覧は「日時→板名→雪質」の同じヘッダーを使用。ビンディングは名前だけを表示し、カード・詳細一覧では読み上げ用のラベルだけ保持しています。

上部の案選択、3案を並べる、配色、詳細／シンプル表示、架空データ例を変更できます。各画面の検索・絞り込み・お気に入りは全案で共通。星はメモリ内だけで変更します。「この設定を確認」はダイアログで全設定を表示し、実際のフォームは更新しません。削除や実データの取り込み機能はありません。

すべて架空の板・設定です。安全な取り付け方や推奨値を示していません。未入力を0で補わず、日時・板名なし、長い文字列、0、旧記録を比較できます。記号を含む入力はエスケープします。

## 分離と検証
